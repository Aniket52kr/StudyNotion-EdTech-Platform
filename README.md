<h1 align="center" id="title">StudyNotion</h1>


<p id="description">StudyNotion is an EdTech platform designed to provide an intuitive user-friendly experience for both students and instructors. The platform offers features such as course enrollment payment processing real-time data visualization for instructors and dashboards to track student progress. Built with a Node.js backend React.js frontend and MongoDB database StudyNotion is a scalable and feature-rich solution for online learning.</p>

  
---

## 🧠 Features

- **User Authentication**  
  Secure login/register for students and instructors using JWT.

- **Course Enrollment**  
  Browse courses, enroll, watch videos, and track completion progress.

- **Instructor Dashboard**  
  Create and manage courses, upload content, track student progress, and view earnings.

- **Payment Integration**  
  Integrated Razorpay payment gateway for secure course purchases.

- **Data Visualization**  
  Real‑time charts and analytics for income, course performance, and enrollment stats.

- **Responsive Design**  
  Fully responsive UI that works smoothly on desktop, tablet, and mobile.

- **Secure & Scalable Deployment**  
  Deployed on AWS EC2 using Docker, Docker Compose, nginx reverse proxy, HTTPS, and GitHub Actions CI/CD.

---
  
## 💻 Built With

Technologies used in the project:

- **Frontend**: React.js, Redux, TailwindCSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Authentication**: JWT + cookies  
- **Payments**: Razorpay  
- **DevOps & Deployment**:  
  - Docker, Docker Compose  
  - Nginx (reverse proxy)  
  - AWS EC2 (Ubuntu)  
  - DuckDNS (dynamic DNS)  
  - Let’s Encrypt (SSL/TLS via Certbot)  
  - GitHub Actions (CI/CD with self‑hosted runner on EC2)
